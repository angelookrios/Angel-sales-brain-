# Angel Sales Brain
**Un segundo cerebro operativo para ventas, prospección y construcción de sistemas comerciales.**

---

## ¿Qué es esto?

No es una empresa ni un producto SaaS. Es mi sistema operativo personal para ventas y prospección, construido mientras me desarrollo como setter en el ecosistema de Axel Jutoran y estudio FIA Agéntica.

El objetivo es tener una única fuente de verdad para todo lo que toca ventas: procesos, scripts, prospectos, aprendizajes y herramientas.

---

## Problema que resuelve

La información comercial suele estar dispersa entre chats, documentos y notas. Este sistema centraliza todo.

---

## Qué contiene (o va a contener)

- Prospección y generación de oportunidades
- Trabajo como setter: scripts, procesos, objeciones
- Investigación de prospectos
- Sistemas de seguimiento de leads
- Automatizaciones con IA (futuro)
- Documentación de aprendizajes
- Herramientas comerciales propias

---

## Estado actual

**Fase de diseño y documentación.** El foco inmediato es construir el sistema operativo de ventas, no desarrollar software complejo.

---
