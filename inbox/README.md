# Inbox — Material Crudo

Acá tirás el material sin procesar:
- Capturas de prospectos (LinkedIn, Instagram, etc)
- Transcripciones de llamadas
- Notas de reuniones
- PDFs o documentos de clientes
- Cualquier cosa que sea info "raw"

Yo consumo esto, lo proceso con **Setter Intel** y lo muevo a `/prospectos/` analizado y listo.

**Patrón de nombramiento:** `[fecha]-[nombre-prospecto]-[tipo].md` o `.png`
Ej: `2026-06-11-acme-corp-linkedin.md`, `2026-06-11-juan-perez-captura.png`
